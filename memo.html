コピー用メモ

青いボタンを押すとコピーされます。Claude のアプリの入力欄で右クリック →「貼り付け」（または Ctrl + V）で貼り付けて、Enter を押してください。

ステップ3：秘書の追加機能を入れる

貼る場所：個人のパソコンの Claude のアプリ、Code タブ（my-company を開いた状態）の入力欄

次の2つのプラグインを、ユーザー全体（どのフォルダでも使える形）で入れてください。
1. GitHub の inoshinichi/bootcamp-company にある company プラグイン
2. anthropics/claude-plugins-official にある superpowers プラグイン
入れ終わったら、アプリを開き直す必要があるか教えてください。

ステップ4：秘書を呼び出す（ステップ3が終わってから）

貼る場所：同じ入力欄。アプリを開き直すように言われたら、開き直して my-company を選び直してから貼ります

/company
